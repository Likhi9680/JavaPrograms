# Java 1D Array Programs

This folder contains beginner-friendly Java programs for practising one-dimensional arrays.

## Programs

| File | Concept |
|---|---|
| `MaxElementAndIndex.java` | Finds the maximum value and its index |
| `SumOfArrayElements.java` | Calculates the sum of integer array elements |
| `AvgOfArrayElements.java` | Calculates the average of integer array elements |
| `MergeStringArrays.java` | Merges two string arrays into one array |
| `MinLenWordInArray.java` | Finds the shortest word and its index |
| `MaxLenWordInArray.java` | Finds the longest word and its index |
| `ReverseArray.java` | Reverses the order of a string array |

## Concepts Practised

- Declaring and creating arrays
- Reading array elements using `Scanner`
- Traversing arrays with `for` loops
- Finding minimum and maximum values
- Calculating sum and average
- Working with arrays of strings
- Combining and reversing arrays
- Using `Arrays.toString()` to display an array

## How to Run

1. Open the project in Eclipse.
2. Open the required `.java` file.
3. Run the class containing `main()`.
4. Enter the requested array size and elements.

Each public class name matches its Java filename.
