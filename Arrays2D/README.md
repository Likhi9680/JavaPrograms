# Java 2D Array Programs

This folder contains Java practice programs for two-dimensional arrays (matrices).

## Programs

| File | Concept |
|---|---|
| `SumOf2DArray.java` | Sum of all elements in a matrix |
| `RowWiseSum2DArray.java` | Sum of each row |
| `ColumnWiseSum2DArray.java` | Sum of each column |
| `LargestElementIn2DArray.java` | Find the largest matrix element |
| `SmallestElementIn2DArray.java` | Find the smallest matrix element |
| `SumOfTwo2DArrays.java` | Add corresponding elements of two matrices |
| `CompareMatrixElements.java` | Print 1 for equal corresponding elements and 0 otherwise |
| `IdenticalMatrices.java` | Check whether two matrices are identical |
| `MatrixTranspose.java` | Print the transpose of a matrix |
| `MainDiagonalSum.java` | Sum the main diagonal |
| `SecondaryDiagonalSum.java` | Sum the secondary diagonal |
| `BothDiagonalsSum.java` | Calculate both diagonal sums and their combined sum |
| `DistinctDiagonalSum.java` | Sum diagonal elements without double-counting the center |
| `BoundaryElementsSum.java` | Sum elements on the matrix boundary |
| `InnerElementsSum.java` | Sum elements excluding the boundary |

## Concepts Practised

- Nested `for` loops
- Row and column indices
- Matrix input and output
- Comparing matrix elements
- Matrix transpose
- Main and secondary diagonals
- Boundary and inner-element conditions
- Working with square and rectangular matrices

## Notes

- Diagonal programs require a square matrix.
- Transpose, boundary sum, and inner sum also work with rectangular matrices.
- The inner-element sum is `0` when there are no elements inside the boundary.
- Matrix addition requires both matrices to have the same dimensions.

## How to Run

Open a `.java` file in Eclipse and run the class containing `main()`. Each public class name matches its filename.
