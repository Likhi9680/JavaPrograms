# Java Basics Programs

This folder contains basic Java programs created for practicing fundamental programming concepts and improving problem-solving skills.

## Programs

| Program                     | Concept                            |
| --------------------------- | ---------------------------------- |
| HelloWorld.java             | Basic Java syntax and output       |
| Input.java                  | Taking input using Scanner         |
| SumOfTwoNumbers.java        | Arithmetic operations              |
| DifferenceOfTwoNumbers.java | Subtraction                        |
| ProductOfTwoNumbers.java    | Multiplication                     |
| Division.java               | Division and modulus               |
| Average.java                | Calculating average                |
| EvenOdd.java                | Conditional statements and modulus |
| PositiveNegative.java       | Conditional statements             |
| LargestOfTwo.java           | Comparing two numbers              |
| LargestOfThree.java         | Multiple conditions                |
| SwapTwoNumbers.java         | Variables and swapping             |
| SimpleCalculator.java       | Switch statement                   |
| CheckVowel.java             | Character conditions               |
| CheckAlphabet.java          | Character validation               |
| LeapYear.java               | Logical operators and conditions   |

## Concepts Covered

* Variables and Data Types
* Input and Output
* Arithmetic Operators
* Relational Operators
* Logical Operators
* `if-else` Statements
* `switch` Statements
* Loops
* Basic Problem Solving

## Purpose

These programs are part of my Java practice and help build a strong foundation in programming and problem-solving.
