## Programs and Concepts

### 1. Basic Syntax and Input/Output

Understanding the structure of Java programs, displaying output, and accepting input from users.

| Program | Description |
|---|---|
| `HelloWorld.java` | Prints a basic message to the console. |
| `Input.java` | Accepts user input using the `Scanner` class. |

### 2. Variables, Data Types, and Arithmetic Operations

Practicing variables, numeric data types, and basic mathematical operations.

| Program | Description |
|---|---|
| `SumOfTwoNumbers.java` | Calculates the sum of two numbers. |
| `DifferenceOfTwoNumbers.java` | Calculates the difference between two numbers. |
| `ProductOfTwoNumbers.java` | Multiplies two numbers. |
| `Division.java` | Performs division and modulus operations. |
| `Average.java` | Calculates the average of numbers. |
| `SwapTwoNumbers.java` | Swaps the values of two variables. |

### 3. Conditional Statements and Operators

Using conditions and operators to make decisions based on input values.

| Program | Description |
|---|---|
| `EvenOdd.java` | Checks whether a number is even or odd. |
| `PositiveNegative.java` | Checks whether a number is positive, negative, or zero. |
| `LargestOfTwo.java` | Finds the larger of two numbers. |
| `LargestOfThree.java` | Finds the largest of three numbers. |
| `LeapYear.java` | Checks whether a year is a leap year. |

### 4. Character-Based Programs

Working with characters and checking character conditions.

| Program | Description |
|---|---|
| `CheckVowel.java` | Checks whether a character is a vowel. |

### 5. Switch Statements

Learning how to use `switch` to execute different operations based on a selected case.

| Program | Description |
|---|---|
| `SimpleCalculator.java` | Performs arithmetic operations using a switch statement. |

### 6. Loops and Number-Based Problems

Practicing loops, repeated calculations, number sequences, and mathematical problem-solving.

| Program | Description |
|---|---|
| `Fibonacci.java` | Generates the Fibonacci sequence. |
| `GCD.java` | Calculates the Greatest Common Divisor of numbers. |
| `PrimeCheck.java` | Checks whether a number is prime. |
| `PrimeInRange.java` | Finds prime numbers within a specified range. |
| `HCFANDLCM.java` | Calculates the Highest Common Factor and Least Common Multiple. |

### 7. Arrays in Java

Learning to store multiple values of the same data type in an array and access them using indices.

| Program | Description |
|---|---|
| `MaxElementAndIndex.java` | Finds the maximum element in an integer array and displays its index. |

**Example: Maximum Element and Index**

Input:
```text
5
10 25 7 40 15
```

Output:
```text
value: 40 and index: 3
```

This program demonstrates:
- Declaring an integer array.
- Reading array elements using `Scanner`.
- Traversing an array using a `for` loop.
- Comparing elements to find the maximum value.
- Tracking the index of the maximum element.
- Understanding zero-based indexing in Java.
